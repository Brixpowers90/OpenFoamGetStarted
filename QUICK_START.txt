================================================================================
                    OPENFOAM QUICK START GUIDE
              (No Admin Rights / No PowerShell Required)
================================================================================

RECOMMENDED IMAGE: opencfd/openfoam-default (456 MB - faster download!)
ALTERNATIVE: openfoam/openfoam:v2412 (2-3 GB - includes ParaView)

================================================================================
STEP 1: Install Docker Desktop
---------------------------
1. Download from: https://www.docker.com/products/docker-desktop/
2. Install Docker Desktop
3. Launch Docker Desktop (wait for whale icon to appear)


STEP 2: Download OpenFOAM Image
--------------------------------
Open Command Prompt (cmd) and run ONE of these:

RECOMMENDED (smaller, faster):
    docker pull opencfd/openfoam-default

ALTERNATIVE (with ParaView):
    docker pull openfoam/openfoam:v2412


STEP 3: Create Cases Folder
---------------------------
Create this folder on your computer:
    Documents\OpenFOAM_cases


STEP 4: Start OpenFOAM Container
--------------------------------
Option A: Double-click the file "start_openfoam.cmd" in this folder
         (It will ask you to choose between the two images)

Option B: Open Command Prompt and run ONE of these:

For RECOMMENDED image (opencfd/openfoam-default):
    docker run -it --name my-openfoam -v "%USERPROFILE%\Documents\OpenFOAM_cases:/home/openfoam/cases" opencfd/openfoam-default

For ALTERNATIVE image (with ParaView):
    docker run -it --name my-openfoam -v "%USERPROFILE%\Documents\OpenFOAM_cases:/home/openfoam/cases" openfoam/openfoam:v2412


STEP 5: Run Your First Simulation
--------------------------------
Inside the container, copy and paste these commands:

RECOMMENDED: Use built-in tutorial (easiest):
    cd /home/openfoam/cases
    cp -r /opt/openfoam/tutorials/incompressible/icoFoam/cavity .
    cd cavity
    blockMesh
    icoFoam

OR: Create manual test case:
    mkdir -p /home/openfoam/cases/test_icoFoam
    cd /home/openfoam/cases/test_icoFoam
    
    # Copy all the case files from INSTALL_GUIDE_NO_ADMIN.md
    # Or use the cavity tutorial as shown above
    
    blockMesh
    icoFoam


STEP 6: Visualize Results
--------------------------
Option A: If using openfoam/openfoam:v2412 (has ParaView):
    paraFoam

Option B: On your host machine (RECOMMENDED):
1. Download ParaView: https://www.paraview.org/download/
2. Install ParaView
3. Open ParaView
4. Navigate to: Documents\OpenFOAM_cases\cavity (or test_icoFoam)
5. Open the .foam file
6. Click Apply to see your simulation!


STEP 7: Restart Later
----------------------
To restart your container with all files intact:
    docker start -ai my-openfoam


================================================================================
                            TROUBLESHOOTING
================================================================================

PROBLEM: Docker not running
SOLUTION: Start Docker Desktop first (whale icon in system tray)


PROBLEM: Permission denied
SOLUTION: On Linux, run: sudo usermod -aG docker $USER then logout/login


PROBLEM: Can't access files after exit
SOLUTION: Files are in Documents\OpenFOAM_cases - just restart container


PROBLEM: Out of memory
SOLUTION: In Docker Desktop: Settings > Resources > Increase memory


PROBLEM: Corporate firewall blocking Docker?
SOLUTION: Ask IT to allow connections to hub.docker.com (port 443)

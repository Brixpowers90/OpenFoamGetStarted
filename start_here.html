\ud83d\ud83\ufe0f OpenFOAM Quick Start Guide

No Admin Rights Required - Perfect for Corporate PCs

\u2728 RECOMMENDED: Use opencfd/openfoam-default (456 MB) - Faster download on corporate networks!
\ud83d\udc81 Welcome! This guide helps you install and run OpenFOAM using Docker without requiring administrator privileges. Perfect for corporate environments where PowerShell scripts (.ps1) are blocked.

\ud83d\udcc1 Step 1: Install Docker Desktop

Docker is required to run OpenFOAM in a container.

Download Docker Desktop:

Download Docker Desktop

Installation:

  • Run the downloaded installer
  • Follow the installation prompts
  • Restart your computer when prompted
  • Launch Docker Desktop from the Start Menu
  • Wait for the whale icon \ud83d\udc33 to appear in the system tray
Note: Docker Desktop is free for personal use and many corporate environments.

\ud83d\udce9 Step 2: Download OpenFOAM Docker Image

Open Command Prompt (cmd) and run ONE of these:

\u2728 RECOMMENDED (456 MB - Faster!):

docker pull opencfd/openfoam-default
  • Smaller size (456 MB)
  • Includes runtime, source, tutorials, dev tools
  • Faster download on corporate networks
  • ParaView not included (download separately)

Alternative (2-3 GB - Includes ParaView):

docker pull openfoam/openfoam:v2412
  • Includes ParaView
  • Larger size (2-3 GB)
  • Slower download
For corporate environments: We strongly recommend opencfd/openfoam-default as it's significantly smaller and less likely to be blocked by IT policies.

\ud83d\udcc2 Step 3: Create Cases Folder

Create a folder for your simulation cases:

Documents\OpenFOAM_cases

You can create this folder using File Explorer.

\ud83d\udc33 Step 4: Start OpenFOAM Container

Option A: Easiest Method

Double-click this file:

\ud83d\udccv start_openfoam.cmd

It will ask you to choose between the two images.

Option B: Manual Method

Open Command Prompt and run ONE of these:

For RECOMMENDED image (opencfd/openfoam-default):

docker run -it --name my-openfoam -v "%USERPROFILE%\Documents\OpenFOAM_cases:/home/openfoam/cases" opencfd/openfoam-default

For ALTERNATIVE image (with ParaView):

docker run -it --name my-openfoam -v "%USERPROFILE%\Documents\OpenFOAM_cases:/home/openfoam/cases" openfoam/openfoam:v2412
\u2705 Success! You're now inside the OpenFOAM container.

\ud83d\udca1 Step 5: Run Your First Simulation

Inside the container, copy and paste these commands:

\u2728 RECOMMENDED: Use built-in tutorial (easiest)

cd /home/openfoam/cases && cp -r /opt/openfoam/tutorials/incompressible/icoFoam/cavity . && cd cavity
blockMesh
icoFoam

What this does:

  • cp -r ... copies the cavity tutorial case
  • blockMesh creates the computational mesh
  • icoFoam runs the incompressible flow solver
  • Simulation runs for a short time
Tip: The opencfd/openfoam-default image includes many tutorials in /opt/openfoam/tutorials

\ud83d\udcc8 Step 6: Visualize Results

Option A: Use ParaView Inside Container (only for openfoam/openfoam:v2412)

paraFoam
  • Navigate to /home/openfoam/cases/cavity
  • Open the cavity.foam file
  • Click Apply to see your simulation results

Option B: Use ParaView on Your Host Machine (RECOMMENDED)

Since opencfd/openfoam-default doesn't include ParaView:

  1. Download ParaView
  2. Install ParaView
  3. Open ParaView
  4. Navigate to: Documents\OpenFOAM_cases\cavity
  5. Open the cavity.foam file
  6. Click Apply to visualize

\ud83d\udcde Step 7: Restart Later

To restart your container with all files intact:

docker start -ai my-openfoam

To stop the container:

docker stop my-openfoam

\ud83d\udca1 Pro Tips

  • Copy files from container: docker cp my-openfoam:/path/in/container C:\path\on\host
  • List running containers: docker ps
  • List all containers: docker ps -a
  • Remove container: docker rm my-openfoam
  • Remove image: docker rmi opencfd/openfoam-default
  • Explore tutorials: ls /opt/openfoam/tutorials

\u2753 Troubleshooting

Docker not running?

  • Windows/macOS: Start Docker Desktop (whale icon in system tray)
  • Linux: Run sudo systemctl start docker

Permission denied?

  • On Linux, add your user to the docker group: sudo usermod -aG docker $USER
  • Then log out and log back in

Can't access files after container exit?

Your files are safe in Documents\OpenFOAM_cases. Just restart the container with the same -v volume mount.

Out of memory?

In Docker Desktop: Settings \u276f Resources \u276f Increase memory allocation

Corporate firewall blocking Docker?

Ask IT to allow connections to:

  • hub.docker.com (port 443)
  • ghcr.io (port 443)

Proxy settings?

In Docker Desktop: Settings \u276f Resources \u276f Proxies
